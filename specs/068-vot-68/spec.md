# Feature Specification: Voting help guide

**Feature Branch**: `codex/vot-68`

## Requirements

- **FR-001**: Provide an accessible bilingual `/voting-help` guide covering registration, accessibility, language help, and moved voters.
- **FR-002**: Publish typed reviewed official resources for every state and DC with fallback/unknown review metadata.
- **FR-003**: Include reviewed PA, AL, and AK identification summaries with source links.
- **FR-004**: Link the guide from polling and voter-info pages without inferring eligibility or collecting sensitive attributes.

## Success Criteria

- SC-001: All 51 jurisdictions have a resource record and deterministic tests validate coverage.
- SC-002: UI exposes source/review status and works in English and Spanish with keyboard navigation.
