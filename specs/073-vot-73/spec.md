# Feature Specification: Military and overseas voting help

**Feature Branch**: `codex/vot-73`

Provide a standalone `/military-overseas` guide requiring no address or account. Explain voting residence versus mailing address, FPCA registration and FWAB emergency voting, never-resided citizens, and official state resources. Do not collect sensitive attributes or reuse domestic deadlines.

## Success Criteria

- All 50 states have typed fallback resources for FPCA, FWAB, and state election offices.
- English/Spanish accessible UI and deterministic resource coverage tests pass.
